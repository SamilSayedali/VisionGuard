# VisionGuard
🚀 Introducing VisionGuard AI – My New Computer Vision Project!

I'm excited to share my latest project: VisionGuard AI, an AI-powered object detection and video analytics application.

The project uses YOLO, Python, and OpenCV to detect and analyze objects in images and videos.

Key Features:

Real-time-style object detection on uploaded media.

Image and video analysis.

Bounding box visualization.

Object counting and detection statistics.

CSV export for analytical results.

Interactive Streamlit dashboard.

Technologies:
Python | YOLO | OpenCV | Deep Learning | Computer Vision | Streamlit | Pandas

This project helped me develop my practical skills in Computer Vision, AI integration, and building interactive machine learning applications.
